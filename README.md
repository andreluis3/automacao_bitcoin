# ₿ Bitcoin Monitor Bot

Bot desenvolvido em **Python** para monitoramento de preços e dados do mercado de criptomoedas.

O projeto coleta informações do **Bitcoin (BTC)** a partir de APIs públicas, processa os dados e permite acompanhar variações de preço em tempo real ou em intervalos definidos.

Este projeto foi criado com o objetivo de praticar **integração com APIs, manipulação de dados e automação utilizando Python**.

---

# 🚀 Funcionalidades

* 📈 Monitoramento do preço do Bitcoin
* 🔎 Consulta de dados de mercado em tempo real
* 📊 Processamento e organização de dados
* ⚙️ Automação de coleta de informações
* 🧮 Manipulação de dados utilizando Python

---

# 🛠️ Tecnologias utilizadas

* **Python**
* **Requests** – requisições HTTP para APIs
* **JSON** – manipulação de dados recebidos
* **Pandas** – análise e estruturação de dados
* **NumPy** – operações numéricas

# 📊 Como funciona

1. O sistema realiza requisições para uma API de criptomoedas.
2. Os dados são recebidos em formato **JSON**.
3. O programa processa e organiza as informações.
4. O usuário pode acompanhar o preço e outras métricas do Bitcoin.

# ⚙️ Instalação

Clone o repositório:

```
git clone https://github.com/andreluis3/bitcoin-monitor.git
```

Entre na pasta do projeto:

```
cd bitcoin-monitor
```

Instale as dependências:

```
pip install -r requirements.txt
```

Execute o projeto:

```
python main.py
```
